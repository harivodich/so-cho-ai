# Audit AI/ML — 14/08/2026

## Evidence đã hoàn tất

- Evaluation text có 60 mẫu do dự án tự soạn, nhãn được khóa trước khi gọi model: 23 bán, 18 nhập, 14 chi phí và 5 câu ngoài phạm vi.
- Báo cáo Gemini thật dùng `gemini-2.5-flash` và prompt `text-extraction-v2`; artifact public lưu metric, nhóm lỗi và ví dụ đã được chọn lọc, không phải fixture.
- Data Quality Guard chạy sau Zod, trước màn hình xác nhận: kiểm tra tổng tiền VND, phép nhân, ngày tương lai, giao dịch nhiều hành động và outlier lịch sử. Guard chỉ cảnh báo, không tự sửa hay tự lưu.
- Insight 7 ngày chỉ gửi aggregate do code tính sang Gemini; test contract xác nhận không đưa raw transaction, UID, transcript hoặc audio vào payload.
- Voice public negative-control dùng 30 mẫu FLEURS `vi_vn` có CC-BY-4.0: 15 clip rõ và 15 biến thể nhiễu trắng tái lập ở 20 dB SNR. Kết quả 29/30 từ chối đúng câu ngoài phạm vi; rõ 14/15, nhiễu 15/15; 1 HTTP 502 được tính là thất bại.

## Lệnh kiểm chứng

```powershell
npm run verify:evidence
npm run lint
npm test
npm run build
```

`verify:evidence` kiểm tra coverage và provenance của dataset, model/prompt của text report, điều kiện rõ/nhiễu của FLEURS và các trường không được phép xuất hiện trong toàn bộ artifact public.

## Điều không được tuyên bố

- Text synthetic và FLEURS negative-control không đại diện đầy đủ cho lời nói trong chợ thực tế.
- FLEURS chỉ đo việc từ chối tiếng Việt ngoài nghiệp vụ; không phải accuracy trích xuất giao dịch bằng voice.
- Gemini TTS vẫn `content_blocked`, nên chưa có transaction-audio accuracy để trình bày.
- Audio, transcript, speaker metadata, raw Gemini response và API key không được publish.

## Kiểm tra hạ tầng read-only

- Firestore Native `(default)` đã tồn tại tại `asia-southeast1` trong project `sochoai`.
- Cloud Run Admin API (`run.googleapis.com`) hiện chưa bật; chưa có bằng chứng về Cloud Run URL công khai. Không tự bật API hoặc deploy trong audit vì đây là thay đổi hạ tầng/billing.
